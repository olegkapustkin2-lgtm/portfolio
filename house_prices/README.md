# House Prices: предсказание стоимости жилья

Задача регрессии: предсказать стоимость дома на основе набора характеристик (количество комнат, площадь, год постройки, тип улицы и т.д.).
Проект остается в сыром, неоформленном виде с комментариями и прочим лишним кодом.

## Цель

Построить модель, которая по признакам объекта недвижимости предсказывает его финальную цену (SalePrice).

## Данные

**Источник:** стандартный датасет House Prices.  
**Целевая переменная:** `SalePrice`.

## Этапы работы

1. **Анализ данных (EDA):**
   - Изучение распределений числовых и категориальных признаков.
   - Выявление признаков, наиболее сильно влияющих на цену.

2. **Очистка и обработка данных:**
   - Заполнение пропусков (числовые — медианой, категориальные — модой).
   - Логарифмирование целевой переменной для нормализации распределения.
   - Кодирование категориальных признаков.
   - Создание новых признаков (например, общая площадь, возраст дома).

3. **Построение моделей:**
   - XGBoost.
   - RandomForest.
   - Сравнение моделей через кросс-валидацию.

4. **Оценка качества:**
   - Основная метрика — **RMSLE** (Root Mean Squared Error).

## Результаты

- **Лучшая модель:** XGBoost.
- **RMSE на кросс-валидации:** ~0.12.
- **Вывод:** На цену дома сильнее всего влияют общая площадь, качество дома и район.
