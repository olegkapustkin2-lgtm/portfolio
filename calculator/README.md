# Рукописный калькулятор (мобильное приложение)

Мобильное приложение для Android, которое распознаёт рукописные математические выражения (цифры и знаки) с помощью нейросети и выводит результат.

---

## Цель проекта

Разработать приложение, которое позволяет пользователю рисовать пальцем пример на экране, распознавать его с помощью модели машинного обучения и отображать результат вычисления.
Понять как работают сверточные нейронные сети
---

## Архитектура

### 1. Модель
- **Тип:** Свёрточная нейросеть (CNN)
- **Обучающий датасет:** Изображения знаков и чисел
- **Формат:** TensorFlow Lite (TFLite) для работы на устройстве

### 2. Мобильное приложение
- **Язык:** Kotlin
- **Платформа:** Android
- **Взаимодействие с моделью:** TFLite Interpreter
- **Холст:** пользователь рисует пример пальцем

### 3. Логика работы
1. Пользователь рисует пример на холсте (например, `5+3`)
2. Приложение обрабатывает изображение
3. Модель распознаёт символы
4. Вычисляется результат (`5+3=8`)
5. Результат отображается пользователю
