# Student Health Prediction

**Цель проекта** — предсказать состояние здоровья студентов (fit, at-risk, unhealthy) на основе данных об образе жизни, физической активности и привычках сна.

## Данные
- **Объём:** 690 088 записей
- **Признаки:** 14 (возраст, ИМТ, длительность сна, уровень стресса, тип диеты и др.)
- **Дисбаланс классов:** ~85% — класс `at-risk`, что делает задачу особенно чувствительной к выбору метрики
- **Пропуски:** присутствуют во всех колонках (от 3% до 10%)

## Технологии
- Python 3.13
- Pandas, NumPy, Matplotlib, Seaborn
- Scikit-learn, CatBoost, LightGBM, ExtraTrees
- Optuna (подбор гиперпараметров)

## Итоговый пайплайн
1. **Feature Engineering** — добавлены новые признаки на основе матрицы корреляций и важности признаков (CatBoost Feature Importance)
2. **Ансамблирование** — стэкинг из трёх базовых моделей (CatBoost, LightGBM, ExtraTrees) с кросс-валидацией (5 фолдов) и мета-моделью LogisticRegression
3. **Оптимизация** — подбор гиперпараметров через Optuna с последующей ручной донастройкой
4. **Результат:** Balanced Accuracy — **0.949**

## Что было попробовано (и что не сработало)

### 1. Кастомный импьютер для заполнения пропусков
Разработал класс, который обучал отдельную модель для каждой колонки с пропусками, чтобы предсказывать пропущенные значения на основе других признаков.

**Результат:** прирост точности оказался незначительным (~0.0003).  
**Вывод:** важные для предсказания признаки не коррелируют между собой настолько, чтобы модель могла качественно восстановить пропуски. Возможно, имело бы смысл применить импьютацию только к парам коррелирующих признаков (например, `уровень_физ_активности` и `длительность_тренировки`), но в рамках этого проекта подход не оправдал себя.

### 2. Прокси-признаки
Добавлял предсказания вспомогательных моделей в качестве дополнительных признаков для улучшения заполнения пропусков. Пробовал разные конфигурации и комбинации колонок.

**Результат:** ни один из вариантов не дал положительного эффекта.  
**Вывод:** использование вероятностных предсказаний для восстановления признаков, которые сами коррелируют с этими вероятностями, создаёт зашумлённую обратную связь. Без качественного исходного признака прокси не помогает.

### 3. Эксперименты с ансамблями
Пробовал разные комбинации базовых моделей и варьировал количество фолдов в кросс-валидации.

**Результат:** CatBoost показал лучший результат на одиночных запусках.  
**Вывод:** в финальном решении можно оставить только CatBoost с разными гиперпараметрами и фолдами, так как он стабильно даёт наилучшее качество.

## Что я вынес из этого проекта
- Не всегда сложное инженерное решение даёт прирост качества — иногда простота оказывается эффективнее.
- Важно быстро проверять гипотезы на кросс-валидации и сравнивать с простыми бейзлайнами.
- Для этой задачи оказалось достаточно чисто обработанных данных, базового заполнения пропусков и правильно настроенного CatBoost.

> Все эксперименты (кастомный импьютер, прокси-признаки, альтернативные ансамбли) сохранены в коде и доступны для ознакомления.
