# Портфолио проектов

Привет! Это моё портфолио проектов по машинному обучению и Data Science. Здесь собраны работы, которые демонстрируют мои навыки в анализе данных, построении и оценке моделей, а также разработке приложений с ML-компонентами.

**Мой подход к обучению:**  
Делаю максимально возможный результат на основе текущих навыков. Затем улучшаю проект через нейросети, разбираю и запоминаю методы улучшения. Перехожу к следующему проекту и повторяю цикл.

---

## Проекты

### 1. Титаник: предсказание выживаемости
Классическая задача бинарной классификации. Проведён анализ данных, созданы новые признаки, обучены и сравнены модели (Logistic Regression, KNN) для предсказания выживания пассажиров.

**Стек:** Python, Pandas, Scikit-learn, Matplotlib, Seaborn.  
[Подробнее...](titanic/README.md)

---

### 2. Предсказание цен на жилье (House Prices)
Задача регрессии. Реализован полный пайплайн: анализ данных, обработка пропусков, инженерия признаков, построение моделей (XGBoost, RandomForest) для предсказания стоимости домов.

**Стек:** Python, Pandas, Scikit-learn, XGBoost, RandomForest, Matplotlib, Seaborn.  
[Подробнее...](house_prices/README.md)

---

### 3. Предсказание состояния здоровья студентов
Многоклассовая классификация. Проведены эксперименты с кастомным импьютером, прокси-признаками и стэкингом моделей (CatBoost, LightGBM, ExtraTrees). Итоговая сбалансированная точность — **0.949**.

**Стек:** Python, Pandas, Scikit-learn, CatBoost, LightGBM, Optuna, Matplotlib, Seaborn.  
[Подробнее...](student_health/README.md)

---

### 4. Рукописный калькулятор (мобильное приложение)
Мобильное приложение на Kotlin, которое распознаёт рукописные математические выражения (цифры и знаки) с помощью модели CNN. Датасет собран через кеш приложения. Модель сконвертирована в TensorFlow Lite для работы на устройстве.

**Стек:** Kotlin, TensorFlow Lite, CNN.  
[Подробнее...](calculator/README.md)
