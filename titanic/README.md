# Titanic: предсказание выживаемости пассажиров

Классическая задача бинарной классификации: предсказать, выжил ли пассажир на «Титанике», на основе его характеристик (пол, возраст, класс и т.д.).

## Цель проекта

Построить модель машинного обучения, которая по данным о пассажире предсказывает его выживание. Это один из самых известных датасетов для старта в Data Science.

## Данные

**Источник:** стандартный датасет Titanic (Kaggle).  
**Целевая переменная:** `Survived` (1 — выжил, 0 — погиб).

## Этапы работы

1. **Анализ данных (EDA):**
   - Изучение пропусков и распределений.
   - Визуализация выживаемости в зависимости от пола, класса, возраста.
   - Анализ корреляций между признаками.

2. **Очистка и обработка данных:**
   - Заполнение пропусков в колонках `Age` (медиана по полу и классу) и `Embarked` (мода).
   - Кодирование категориальных признаков (пол, порт посадки).
   - Создание новых признаков: размер семьи, наличие каюты.

3. **Построение моделей:**
   - Логистическая регрессия.
   - K-ближайших соседей (KNN).
   - Сравнение моделей через кросс-валидацию.

4. **Оценка качества:**
   - Основная метрика — **Accuracy**.

## Результаты

- **Лучшая модель:** KNeighborsClassifier.
- **Точность на кросс-валидации:** `~0.815`.
- **Вывод:** Наиболее важными признаками оказались пол, класс и возраст.
